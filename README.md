## 📖 Descrizione

**LazZaro Script** (originariamente PizzaScript) è una collezione completa di script per mIRC sviluppata da Stefano Basile (alias Dylan, LazZaro, Bios) e il PizzaTeam tra il 1998 e il 2000. Questo progetto rappresenta uno dei più sofisticati e completi script mIRC dell'epoca, combinando funzionalità di amministrazione IRC, strumenti di sicurezza, elementi sociali e una vasta gamma di addon.

## 🎯 Caratteristiche Principali

### 🛡️ Sistema di Protezione IRC
- **Flood Protection**: Protezione contro flood di testo, CTCP, nick, join, inviti, topic
- **Mass-mode Protection**: Protezione contro mass-deop, mass-op, mass-kick
- **Anti-Clone**: Rilevamento e gestione cloni
- **Servermode Protection**: Protezione contro deop automatici del server
- **Desynch Protection**: Protezione contro desincronizzazioni

### 👥 Gestione Utenti e Liste
- **Auto-op List**: Gestione automatica degli operatori
- **Friend List**: Lista amici con privilegi speciali
- **Shit List**: Lista utenti da bannare automaticamente
- **Notify List**: Gestione notifiche di presenza

### ⚔️ Strumenti di Amministrazione
- **Takeover**: Comando per prendere il controllo di un canale
- **Mass Operations**: Operazioni di massa (kick, ban, op, deop)
- **Channel Management**: Gestione completa dei canali
- **User Management**: Gestione utenti avanzata

### 🎨 Funzionalità Sociali e Divertimento
- **ASCII Art**: Centinaia di disegni ASCII per saluti, insulti, azioni
- **Sound System**: Sistema audio con MIDI e WAV
- **Paint System**: Sistema di disegno collaborativo
- **Love Actions**: Azioni romantiche e divertenti
- **Barzellette**: Raccolta di barzellette categorizzate

### 🌐 Strumenti di Rete
- **DCC Tools**: Gestione DCC Send/Chat
- **File Server**: Server di file con crediti e limiti
- **Telnet Client**: Client telnet integrato
- **DNS Tools**: Strumenti per risoluzione DNS
- **Finger**: Client finger integrato

## 🚀 Installazione

1. **Requisiti**:
   - mIRC 5.4x o superiore
   - Windows 95/98/NT

2. **Installazione**:
   - Estrai tutti i file in una directory dedicata
   - Inserisci il file `mirc32.exe` nella directory principale
   - Avvia mIRC e carica lo script

3. **Configurazione**:
   - Usa il menu contestuale per accedere alle opzioni
   - Configura le liste utenti (auto-op, amici, shit-list)
   - Personalizza i messaggi di kick e le protezioni
